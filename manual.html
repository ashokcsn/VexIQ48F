Autonomous Routines (src/Auton-48F-WithInertial.iqblocks)

Modular autonomous routine utilizing custom function blocks (pickAndLoadBag and fireAndReloadCatapult) and absolute gyro heading tracking.

Why "WithInertial" is Recommended: Uses turn to heading (TurnAngleDeg) and turn to heading (0). This locks the robot to absolute field coordinates on every cycle, eliminating angle drift across the entire 60-second Skills match!

Autonomous Bag Cycle Workflow

  1. Pick & Load (pickAndLoadBag): Lowers arm ClawAboveGroundDeg, drives forward MoveBeforePickmm, clamps, lifts ClawMotorMoveDeg over bucket, releases, returns arm.
  2. Drive Forward: Drives forward DriveForwardDistMM mm toward the launch zone.
  3. Aim & Throw: Turns to heading TurnAngleDeg, fires catapult for CataThrowTimeSec, rewinds for CataWindTime, holds tension.
  4. Straighten & Return: Turns back to heading 0°, reverses DriveForwardDistMM mm back into the loading zone wall, settles for WaitAtLoadingZoneSec, and repeats.

PID Autonomous (src/Auton-48F-PID.iqblocks / src/Auton-48F-PID.iqpython)

Same bag cycle as Auton-48F.iqblocks, but every drive and turn is closed-loop so the robot stops drifting. Two equivalent versions: Blocks (Auton-48F-PID.iqblocks, slot 5) and Python (Auton-48F-PID.iqpython, slot 6; source in src/Auton-48F-PID.py). Both files are generated by tools/gen_auton_pid.py.

How it works: pidDrive reads both drive motor encoders → distance PID sets forward speed (with a soft-start slew limit), while the brain inertial sensor holds TargetRotation by speeding up one side and slowing the other. pidTurn runs a PID on inertial rotation. Each move ends when the error stays inside the tolerance for PidSettleSec, or when its timeout expires.

PID Bag Cycle Workflow

  1. Pick & Load (pickAndLoadBag): Lowers arm ClawAboveGroundDeg, PID-drives forward MoveBeforePickIn (timeout MoveBeforePickTimeoutSec), clamps, lifts ClawMotorMoveDeg, releases, PID-drives back MoveBeforePickIn, returns arm.
  2. Reverse to Goal: pidDrive reverses DriveDistIn inches holding heading.
  3. Aim & Throw: TargetRotation −= TurnAngleDeg (turn left), pidTurn, then fireAndReloadCatapult.
  4. Straighten & Return: TargetRotation += TurnAngleDeg, pidTurn, pidDrive forward DriveDistIn, wait WaitAtLoadingZoneSec, repeat until AutonDurationSec.

Distance Calibration (do this first)

  1. Set DriveDistIn to 24 and run one cycle. Measure how far the robot actually travels.
  2. Set DriveCalibration = measured inches ÷ 24 (e.g. robot went 30″ → 1.25). Robot drives too short → value below 1.
  3. If turns overshoot/oscillate lower TurnKp or raise TurnKd; if the robot still curves raise HeadingKp (0.5 steps); if it wobbles side to side lower it.

Competition Match-Day Checklist

  • Air Pressure: Ensure pneumatic tank is pressurized and compressor turns ON at startup.
  • Autonomous Alignment: For Auton-48F-WithInertial, square the robot flush against the loading zone wall pointing straight ahead (0°) before starting program calibration.
  • PID Auton: For Auton-48F-PID, keep the robot completely still during the ~2 s inertial calibration, and re-check DriveCalibration after any wheel or gear change.
  • Driving Skills Ready: Driving skills has zero calibration delay. Start driving the moment the buzzer sounds!
  • Catapult Tension: Ensure rubber bands are properly seated on the catapult arm. Use Button L-Down for manual tension check if needed.
